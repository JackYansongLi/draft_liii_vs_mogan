\section*{Limitations}

First, we did not fully compare Mogan STEM with Markdown in our experiments. Markdown is a lightweight language designed for daily notes. It lacks advanced typesetting features, such as customized templates and complex references. Given the huge gap in their application scenarios, designing fair comparative experiments is difficult.

Second, Markdown uses the same {\LaTeX} grammar for mathematical formulas. In Section~\ref{sec:eff-in-sft}, we showed that this {\LaTeX} grammar is less efficient for LLM fine-tuning than Mogan's S-expressions. We believe this conclusion also holds for Markdown as a ``Documentation-Oriented Architecture''~{\cite{filho_doa_2026}}. However, we did not empirically test this due to resource constraints.

Finally, our current evaluation focuses mainly on LLM writing and training efficiency. We still need more experiments to evaluate other aspects, such as extensibility, semantic richness, and typographic precision. Due to computational and budget limits, we leave these large-scale evaluations for future work.
